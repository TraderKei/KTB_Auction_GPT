# KTB_AUCTION_V2 데이터 기준

앞으로 화면 데이터는 재정경제부 국채시장·입찰결과 공시와 한국은행 공고·ECOS를 우선한다. 두 기관에서 확인되지 않는 값만 화면 예시용 더미로 보완하고, 더미임을 화면에 표시한다. 원천 공시값, 파생값, 더미값, 미확보값을 서로 구분한다.

## 현재 v2 스냅샷

- `mockup/ktb-terminal-v3-data.js`: 재정경제부 원문 보존본에서 생성된 2026년 1~10월 발행계획 10건, 경쟁입찰 결과 79건, 비경쟁 결과 공시 48건(유형별 95개 값), 매입·교환 이벤트 18건. 결과는 10월 8일까지만 일부 보존됐으며 10월 전체를 포괄하지 않는다. 비경쟁 결과는 9월까지 보존됐다. 같은 날·만기·원천 종목명이 일치하는 계획과 결과만 연결한다. 원천의 `국고00000` 임시 종목명과 실제 발행 종목을 추측해 연결하지 않는다.
- `discovery/raw/ecos/search-market-30y-20261007.json`: ECOS `817Y002 / D / 010230000`, 2026-10-07 국고채 30년 유통금리 4.491%. 이 값은 참고 지표이며 낙찰금리로 사용하지 않는다.
- 화면의 2025년 비교값, 연간 목표·만기 구조, 수요점수, 민평대비 스프레드는 더미로 남는다. `data-source="DEMO"`와 별표를 표시한다. 민평금리는 두 공식 원천에서 확보되지 않아 스프레드 더미를 실측 지표로 해석하면 안 된다.
- 상환원금과 교환 순증감은 미확보이므로 순공급을 계산하지 않는다. 월별 발행·매입 합계는 보존된 공시의 **관측분**이며 공식 월간 총계가 아니다.

`node scripts/build_ktb_auction_v2.js`로 v1을 건드리지 않고 v2를 재생성한다. 브라우저 검증은 Playwright와 Edge가 있는 환경에서 `node scripts/check_ktb_auction_v2.js`를 실행한다. 보존 원천에 새 공시를 추가한 뒤 재생성해야 화면이 갱신된다.
