# KTB_AUCTION_V2 데이터 기준

앞으로 화면 데이터는 재정경제부 국채시장·입찰결과 공시와 한국은행 공고·ECOS를 우선한다. 두 기관에서 확인되지 않는 값만 화면 예시용 더미로 보완하고, 더미임을 화면에 표시한다. 원천 공시값, 파생값, 더미값, 미확보값을 서로 구분한다.

## 현재 v2 스냅샷

- `data/ktb-v2-source.json`: 보존된 재정경제부 원문을 해석한 2026년 1~10월 발행계획 10건, 경쟁입찰 결과 79건, 비경쟁 결과 공시 48건(유형별 95개 값), 매입·교환 이벤트 18건과 ECOS 응답 한 건을 재생성 입력으로 고정했다. 재정경제부 결과는 10월 8일까지만 일부 보존됐고 비경쟁 결과는 9월까지 보존됐다.
- ECOS `817Y002 / D / 010230000`: 2026-10-07 국고채 30년 유통금리 4.491%. 참고 지표이며 개별 입찰 낙찰금리가 아니다.
- 같은 날·만기·원천 종목명이 일치하는 계획과 결과만 연결한다. `국고00000` 임시 종목명과 실제 발행 종목은 추측해 연결하지 않는다. 연결되지 않은 계획 19건은 **모형 입찰결과**를 만든다.

## 모형값 생성 규칙

- 결과가 없는 계획의 응찰액은 같은 만기의 공식 결과 응찰배수 중앙값 × 예정액, 낙찰액은 예정액으로 둔다. 낙찰금리는 날짜가 가장 가까운 같은 만기의 실제 결과금리를 기준으로 소폭 조정하고, 최고·최저금리 간격은 각각 약 0.009·0.012%p로 둔다. 공시 결과에 일부 금리만 있는 경우에도 같은 방식으로 빈 칸만 보완한다.
- 민평대비 스프레드는 실제 민평금리가 없으므로 응찰배수와 테일을 이용해 -1.8~+2.2bp 범위에서 만든다. 수요점수는 응찰배수·테일·이 모형 스프레드로 20~85점 범위에서 계산한다.
- 2026년 1~10월 만기별 월간 계획은 보존된 공시를 사용한다. 11~12월은 최근 네 달 중앙값에 각각 90%·70%를 적용한다. 2025년 월간 비교값은 2026년 대응 월 대비 약 ±4.5%로 만들고, 연간·그룹 전망은 해당 월별 합계와 맞춘다.
- 비경쟁 인수액과 참여기관수는 공시값을 유지한다. 경쟁낙찰액이 연결되지 않는 행은 비경쟁 인수액의 약 6배를 기준으로 보완하고, 같은 종목·월의 여러 인수유형에 한 번만 배분한다.
- 월간 발행액은 공시 월간 경쟁입찰 계획의 약 99%와 비경쟁 관측액(없으면 경쟁액의 7%)을 합친 모형값이다. 만기상환은 모형 발행액의 약 42%, 미관측 매입은 약 4.5%, 교환 순증감은 ±1% 이내로 둔다. **순공급 = 발행 − 상환 − 매입 + 교환**으로 계산한다. 이 비율은 화면 시뮬레이션용이며 공시 사실이나 전망치가 아니다.

모형값 셀에는 `data-source="DEMO"`와 별표를 표시한다. 공식 결과 행 중 일부 빈 필드만 보완한 경우에는 그 셀에만 별표를 붙인다. 민평대비·상환·순공급을 투자 판단에 사용할 수 없다.

`node scripts/build_ktb_auction_v2.js`로 v1을 건드리지 않고 v2를 재생성한다. 브라우저 검증은 Playwright와 Edge가 있는 환경에서 `node scripts/check_ktb_auction_v2.js`를 실행한다. 보존 원천에 새 공시를 추가한 뒤 재생성해야 화면이 갱신된다.
